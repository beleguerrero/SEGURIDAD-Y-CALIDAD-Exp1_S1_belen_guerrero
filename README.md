
# Exp1_S1_belen_guerrero
Actividad Formativa 1: Creando una aplicación web segura usando frameworks y librerías de seguridad

## Tecnologías

- Java
- Spring Boot
- Thymeleaf
- Spring Security
- Tailwind CSS

## Ejecución

Ejecutar el proyecto desde el IDE o mediante Maven:

```bash
mvn spring-boot:run
```

La aplicación estará disponible en:

http://localhost:8081
